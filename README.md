# AudioRubrics Project Page

Project page for **Reinforcement Learning with Evolving Rubrics as Rewards for Audio Reasoning** (AudioRubrics).

Adapted from the [Nerfies](https://nerfies.github.io/) website template.

## Local preview

```bash
python -m http.server 8001
# then visit http://localhost:8001
```

```
.
├── index.html
├── .nojekyll            # tells GitHub Pages to skip Jekyll processing
└── website/
    ├── css/             # index.css, style.css
    └── img/             # figures converted from the paper PDFs
```
